# Week 10 - Salary Calculator

This project demonstrates a modular Python payroll system with separate files for:

- employee.py: collects employee details
- salary.py: calculates gross salary, EPF, SOCSO, and net salary
- report.py: displays the salary summary
- main.py: coordinates the workflow

## Features
- Calculates overtime pay at RM25 per hour
- Adds a service bonus for employees with more than 3 years of service
- Displays a salary summary report

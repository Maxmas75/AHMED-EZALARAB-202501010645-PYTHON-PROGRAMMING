# Week 8 Food Delivery Receipt Generator

## Purpose
This application collects customer order details and prints a simple food delivery receipt with subtotal, service charge, and delivery charge.

## Tech Stack
- Python 3
- Standard input/output

## How to Use
1. Run the application with: `python3 week_8/main.py`
2. Enter the customer name.
3. Enter the food item.
4. Enter the quantity.
5. Enter the price per item.
6. Enter `Y` for delivery or `N` for no delivery

# IT Helpdesk Ticket Registration System

## Purpose
This application is a simple IT helpdesk ticket registration system for City University Malaysia students.
Students can submit a ticket with their name, ID, issue, location, and priority. The ticket is then assigned a technician and a pending status.

## Tech Stack
- Python 3

## How to use
1. Open a terminal in the repository root.
2. Change to the `week_9` directory:
   ```bash
   cd week_9
   ```
3. Run the program:
   ```bash
   python3 main.py
   ```
4. Enter the requested information.
5. Review the displayed ticket details.

## Priority assignment
- High = Ahmad
- Medium = Siti
- Low = Ali

## Notes
- The ticket system uses a modular structure with `main.py`, `ticket.py`, and `display.py`.
- `main.py` runs the program and displays the ticket.
- `ticket.py` creates the ticket and assigns a technician.
- `display.py` prints the ticket details.
